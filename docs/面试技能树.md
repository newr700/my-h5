# 前端面试技能树（Vue 方向 · 加点面板）

> 用法：每一层里的技能点，面试都会问，本仓库里都有实体代码对应。
> 每个点标注：**项目落点**（去哪看真实代码）+ **面试怎么考**（真题长什么样）。
> 加点顺序建议自下而上——下层是上层的前置。

## T0 语言基础（必点满，问得最狠的一层）

| 技能点 | 项目落点 | 面试怎么考 |
| --- | --- | --- |
| JavaScript ES6+（解构、箭头函数、模板字符串、模块） | 全部 `.ts`/`.vue` 文件 | `const` 和 `let` 区别？ESM 和 CommonJS 区别？ |
| TypeScript（泛型、类型收窄、utility types） | `api/request.ts` 的 `get<T>`、`Partial<ApiResponse>` | `unknown` 和 `any` 区别？什么时候用泛型？ |
| 类型体操入门（自定义类型守卫） | `utils/validate.ts` 的 `isPlainObject` | 写一个判断类型的函数，返回值怎么影响 TS 推断？ |
| CSS 布局（flex） | `StandingsList.vue` 的 `.row` | flex: 1 是什么意思？主轴交叉轴？ |
| CSS 移动适配 | `vite.config.ts` 的 pxToViewport | rem 和 vw 方案各怎么算？1px 边框问题？ |

## T1 框架核心（Vue 面试的主战场）

| 技能点 | 项目落点 | 面试怎么考 |
| --- | --- | --- |
| 组合式 API（`<script setup>`、ref/computed） | `views/standings/StandingsList.vue` | ref 和 reactive 怎么选？为什么 ref 要 .value？ |
| 响应式原理 | 同上（数据变了模板自动更新） | Vue3 用 Proxy 重写响应式，好处是什么？ |
| 生命周期 | `onMounted` 发请求（StandingsList） | 为什么发请求写在 onMounted 不写在 setup 顶层？ |
| 条件渲染与列表 | `v-if` 三态切换、`v-for` + `:key` | :key 用 index 会出什么问题？v-if 和 v-show 区别？ |
| 组件通信 | store 模式（跨页面共享数据） | props/emit、provide/inject、store 各适用什么场景？ |
| 计算属性 vs 方法 | `zones`、`isInitialLoading` 都是 computed | computed 有缓存，什么时候会重算？ |
